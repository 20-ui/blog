# OpenWrt + splify2: полное руководство по настройке VPN-роутера

Инструкция проводит весь путь от чистой сборки прошивки до работающего обхода блокировок: собираем образ с нужными пакетами, устраняем конфликт подсетей, подключаем роутер к домашней сети по кабелю или «по воздуху» (WISP) и поднимаем туннель через **splify2**.

> 📌 В примерах используется **Cudy TR3000** (MediaTek MT7981). Инструкция универсальна для любого роутера с поддержкой OpenWrt — отличаться будет только список платформо-зависимых пакетов (драйверы Wi-Fi/USB).

## 1. Сборка прошивки с нужными пакетами

Самый удобный способ получить готовую систему — собрать образ через официальный **Firmware Selector**, заранее интегрировав в него все необходимые драйверы и пакеты.

1. Откройте [Firmware Selector](https://firmware-selector.openwrt.org/) и введите модель вашего роутера (например, `Cudy TR3000`).
2. Разверните меню **Customize** (Настроить).
3. В поле **Installed packages** вставьте список ниже. В нём стандартный `dnsmasq` заменён на `dnsmasq-full` (жёсткое требование для работы PassWall2/splify2), а также добавлены пакеты для USB, SMB и файловых систем:

```text
apk-mbedtls base-files ca-bundle dnsmasq-full dropbear firewall4 fitblk fstools kmod-crypto-hw-safexcel kmod-gpio-button-hotplug kmod-leds-gpio kmod-nft-offload libc libgcc libustream-mbedtls logd mtd netifd nftables odhcp6c odhcpd-ipv6only ppp ppp-mod-pppoe procd-ujail uboot-envtools uci uclient-fetch urandom-seed urngd wpad-basic-mbedtls kmod-usb3 kmod-mt7915e kmod-mt7981-firmware mt7981-wo-firmware luci luci-app-attendedsysupgrade luci-compat ksmbd-server luci-app-ksmbd vsftpd block-mount kmod-usb-storage kmod-fs-vfat kmod-fs-exfat kmod-fs-ext4 kmod-fs-ntfs3 usbutils
```

4. В поле **uci-defaults script** вставьте код ниже. При первом запуске он включит все радиомодули и автоматически создаст точку доступа с заданными именем и паролем. Это критически важно, если после прошивки у вас нет возможности подключиться к роутеру по кабелю:

```bash
#!/bin/sh

# ЗАДАЙТЕ ИМЯ СЕТИ И ПАРОЛЬ (МИНИМУМ 8 СИМВОЛОВ):
SSID="Cudy-2EDC"
WIFI_PASS="33497723"

# Включаем все доступные радиомодули (2.4GHz и 5GHz)
for r in 0 1 2; do
  if uci -q get wireless.radio${r} > /dev/null; then
    uci -q set wireless.radio${r}.disabled='0'
    uci -q set wireless.radio${r}.country='RU'
  fi
done

# Присваиваем имя сети и пароль всем стандартным интерфейсам
for i in 0 1 2; do
  if uci -q get wireless.default_radio${i} > /dev/null; then
    uci -q set wireless.default_radio${i}.ssid="$SSID"
    uci -q set wireless.default_radio${i}.encryption='psk2'
    uci -q set wireless.default_radio${i}.key="$WIFI_PASS"
  fi
done

uci commit wireless
wifi reload
```

5. Нажмите **Request Build**, дождитесь окончания сборки и скачайте образ с пометкой **`sysupgrade`**.

## 2. Прошивка роутера

1. Зайдите в веб-интерфейс роутера (или_recovery-режим производителя, если OpenWrt ещё не стоит).
2. Перейдите в **System → Backup / Flash Firmware**.
3. Загрузите скачанный образ `sysupgrade`.
4. ⚠️ **Обязательно снимите галочку «Keep settings»** — старые настройки не должны переезжать в новую систему.
5. Дождитесь завершения прошивки и перезагрузки (3–5 минут).

## 3. Базовая настройка сети: устранение конфликта IP

Большинство домашних роутеров используют адрес `192.168.1.1`. Свежепрошитый OpenWrt имеет тот же адрес. Если соединить их как есть, возникнет конфликт подсетей. Перенесём VPN-роутер в другую подсеть — `192.168.10.1`.

1. **Не подключая** VPN-роутер к основному, подключитесь к нему напрямую: по Wi-Fi (`Cudy-2EDC`) или кабелем от компьютера в LAN-порт.
2. Откройте в браузере `192.168.1.1` (пароль по умолчанию отсутствует).
3. Перейдите в **Network → Interfaces**.
4. В строке интерфейса **LAN** нажмите **Edit**.
5. В поле **IPv4 address** измените `192.168.1.1` на `192.168.10.1` и нажмите **Save**.
6. 🛑 **Хитрость со «слепым» сохранением.** Если нажать обычную кнопку *Save & Apply*, включится таймер безопасности на 90 секунд: браузер потеряет связь с роутером из-за смены IP, вы не успеете подтвердить изменения, и роутер откатит адрес обратно.
   - Нажмите на **маленькую стрелочку** рядом с кнопкой *Save & Apply* и выберите **Apply unchecked** (Применить без проверки).
   - Роутер применит новый адрес навсегда. Страница браузера «зависнет» на вечной загрузке — это нормально.
7. Подождите 10–15 секунд, переподключитесь к сети и откройте новый адрес: **`192.168.10.1`**.

## 4. Смена имени Wi-Fi сети и пароля

Если вы хотите изменить SSID и пароль, заданные на этапе сборки (рекомендуется делать это **до** настройки WISP, чтобы не потерять подключение):

1. Перейдите в **Network → Wireless**.
2. Найдите сеть с режимом **Mode: Master** и нажмите **Edit**.
3. На вкладке **Interface Configuration → General Setup** измените поле **ESSID** на желаемое имя.
4. На вкладке **Wireless Security** впишите новый пароль в поле **Key**.
5. Нажмите **Save**, затем **Save & Apply** и переподключитесь к новой сети.

## 5. Подключение к основному роутеру

### 5.1. По кабелю (двойной NAT) — самый надёжный способ

1. Возьмите патч-корд (сетевой кабель).
2. Один конец вставьте в свободный **LAN-порт** основного роутера.
3. Другой конец — в **WAN-порт** VPN-роутера.
4. Интернет появится автоматически.

### 5.2. По воздуху (режим WISP)

Если протянуть кабель невозможно, роутер будет принимать интернет от основной сети по Wi-Fi, прогонять его через VPN и раздавать дальше через свою точку доступа.

1. В веб-интерфейсе `192.168.10.1` перейдите в **Network → Wireless**.
2. Нажмите **Scan** возле радиомодуля, которым будете принимать интернет (для максимальной скорости используйте **5 GHz**).
3. Найдите вашу основную домашнюю сеть и нажмите **Join Network**.
4. Введите пароль от неё в поле **WPA passphrase**.
5. ⚠️ **Критически важно:** в поле **Network** («Имя новой сети») должна быть выбрана сеть **`wwan`**. Если перед вами выпадающий список с галочками — снимите галочки с `lan` и `wan`, оставив только `wwan`.
6. Нажмите **Submit**, затем **Save & Apply**. Интернет появится.

> 💡 **Совет для путешественников.** При частом переподключении к разным сетям (отели, гости) накапливаются «мусорные» интерфейсы `wwan1`, `wwan2`… Чтобы этого избежать, при подключении к новой сети ставьте галочку **Replace wireless configuration** и выбирайте старую клиентскую сеть — пароль просто перезапишется. Либо периодически удаляйте неактуальные сети кнопкой **Remove** в разделе Wireless.

## 6. Установка и настройка splify2

**splify2** — движок и веб-интерфейс для обхода блокировок. Установочный скрипт сам определит архитектуру и менеджер пакетов (`apk` или `opkg`), поставит движок и интерфейс, включит службу. Дальше вся настройка идёт через **LuCI → Сервисы → splify2**: первый запуск проведёт за руку, SSH больше не понадобится.

### 6.1. Установка одной командой

Подключитесь к роутеру по SSH и выполните:

```bash
sh -c "$(wget -qO- https://gitlab.com/xyzmean/splify2/-/raw/main/install.sh)"
```

> 🔒 Если `githubusercontent.com` у вас закрыт — не страшно: главной ссылкой установки стал GitLab, скрипт скачается без проблем.

### 6.2. Требования

- **OpenWrt 22.03 или новее** — поддерживаются оба менеджера пакетов: `apk` и `opkg`;
- **от 2 МБ свободного флеша**: пакет интерфейса ~470 КБ (распакованный — 1,4 МБ), движок 112–299 КБ (распакованный — примерно вдвое больше), остальное занимают скачанные списки. На `jffs2` распакованное сжимается снова, и хватает меньшего;
- **одно из**: ссылка подписки VLESS/Reality · отдельные ссылки `vless://` · уже настроенный WireGuard или AmneziaWG.

> ✅ Все настройки — правила, выходы, подписки, свои списки — переживают обновление прошивки (sysupgrade): скачанные списки роутер после него просто заберёт заново.

### 6.3. Выбор движка: базовый или расширенный

Для работы с подписками **VLESS/Reality** выбирайте **расширенный движок** — туннель должен поднимать сам движок.

| Вариант | Когда брать | Размер пакета* |
| :--- | :--- | :--- |
| **Расширенный (`steer-extended`)** | Туннеля ещё нет: движок сам поднимает подключение по ссылке подписки VLESS/Reality | 263–299 КБ |
| **Базовый (`steer`)** | Туннель уже работает (WireGuard, AmneziaWG, что угодно): движок занимается только маршрутизацией, клиента VLESS внутри нет | 112–127 КБ |

\* Цифры из релиза steer 1.3.0, разброс по шести архитектурам; распакованное на флеше занимает примерно вдвое больше.

Выбор не окончательный: переключатель есть в интерфейсе (карточка движка на первом запуске, позже — в Настройках), все сохранённые настройки при смене движка остаются на месте.

## 7. Приложение: быстрая справка и troubleshooting

### Шпаргалка

| Параметр | Значение |
| :--- | :--- |
| Веб-интерфейс до настройки | `192.168.1.1` (без пароля) |
| Веб-интерфейс после настройки | `192.168.10.1` |
| Wi-Fi сеть (SSID) | `Cudy-2EDC` |
| Пароль Wi-Fi | `33497723` |
| Меню splify2 | LuCI → Сервисы → splify2 |

### Частые проблемы

- **Страница «висит» после смены IP.** Это ожидаемое поведение при *Apply unchecked*: браузер ищет старый адрес. Подождите 15 секунд и откройте `192.168.10.1`.
- **IP откатился обратно на 192.168.1.1.** Вы нажали обычную *Save & Apply* и не успели подтвердить изменения за 90 секунд. Повторите процедуру через *Apply unchecked*.
- **Нет интернета в режиме WISP.** Проверьте, что клиентский интерфейс назначен только в зону `wwan` (пункт 5.2, шаг 5), и что пароль от основной сети введён верно.
- **Не открывается страница установки splify2.** Убедитесь, что служба запущена, и обновите меню LuCI (Logout → Login).
